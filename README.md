## 四、从下单到 SSH：流程和三个容易卡住的地方

VPS 官网下单是五步：挑套餐，选计费周期，选机房，选操作系统（不确定就 Debian 12 或 Ubuntu 22.04，文档多），然后结账。

注册账号这一步有三个地方容易出问题。

**邮箱必须真实。** 账单、服务器登录信息、工单回复全走这个邮箱。姓名用拼音，地址填到街道级，建议如实填，异常订单可能触发人工审核，地址对不上会拖慢开通。

**页面底部的谷歌验证码加载不出来，订单就提交不了。** 表现是点「Complete Order」没反应，多数人第一反应以为卡了，其实是验证码没加载。

**开通邮件里有三套密码，别当成一套。** 官网账号密码、SSH 的 root 密码、控制面板密码互相独立，控制面板那套单独写在开通邮件里，官网现在叫 ctrl。面板里能重装系统、强制重启、开 VNC 救援、看流量图，SSH 进不去的时候靠它救。

付完款几分钟内会收到标题含「KVM VPS Login Information」或「New VPS Server Information」的邮件，里面有 Main IP、Root Password 和面板地址。邮件翻不到就登录官网后台，头像菜单里有 Email History，系统发过的邮件都在里面。SSH 连 22 端口，用户名 root，密码用邮件里那串。

付款方式支持信用卡、PayPal、支付宝和比特币。国内用户走支付宝，扫码支付，按支付时的实时汇率折算，官方没有列额外手续费。有作者反馈支付宝下的单几分钟自动开通，信用卡订单偶尔会触发风控审核，反而更慢。

## 五、买之前必须知道的限制

**不退款。** 官方条款不提供退款，也没有 Money Back Guarantee。买错计费周期、买完发现机房不合适，钱退不回来。所以第一次买，与其纠结配置，不如先确认机房和系统。

**只能升不能降。** 升级补差价，降级不行。

**流量超了直接断网。** 超过月流量后公网访问被暂停，直到下个计费周期重置，不会自动扣费，也不会偷偷限速。选套餐时流量留点余量。

**换机房要开工单，IP 会变。** 前提是目标机房有库存，迁移期间短暂停机。有作者从圣何塞迁到洛杉矶 DC-02，工单提交后大约半天完成，没有收费。

**Windows 要授权。** KVM VPS 支持 Windows 镜像，但得自带授权，或者买价格更高的 Windows VPS 套餐。

**续费价这件事，目前只有第三方作者的说法。** 有教程作者反馈促销款续费价与首发价一致，并举例 2023 年黑五买的 $11/年套餐续到 2026 年还是 $11/年。这不是官方承诺条款，当成参考，别当成合同。
